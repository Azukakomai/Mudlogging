\begin{abstracteng}
In upstream petroleum exploration and drilling operations, subsurface reservoir fluid identification has traditionally relied on post-drilling Wireline Logging (WL) or Logging While Drilling (LWD) suites, which introduces substantial rig standby time, severe borehole hazards, and high service expenditures. While Gas While Drilling (GWD) chromatographic data ($C_1$ through $nC_5$ and $TG$) is acquired continuously during the very first bit run as the rock matrix is crushed, its diagnostic potential remains severely hindered by existing formation evaluation software, which functions primarily as passive, slow-to-configure data plotters lacking automated forecasting logic. Furthermore, non-transparent machine learning models fail strict industry Standard Operating Procedures (SOP) and SPE PRMS Chapter~4 deterministic reserve certification audit mandates. To resolve these operational challenges, this research develops a dedicated, open-source web-based decision support system for automated multi-ratio petrophysical analysis and deterministic hydrocarbon fluid classification. The software automatically ingests raw mud logging files across standard formats (\texttt{.csv}, \texttt{.txt}, \texttt{.xlsx}, \texttt{.las}), computes a comprehensive matrix of 16 derived petrophysical indicators (including classic Pixler ratios, expanded Haworth show ratios $W_h, B_h, C_h$, butane multipliers, and composite indices $GOW, WBS, GOR$), and executes deterministic majority-voting logic to forecast reservoir fluid regimes (Gas Pay Zone, Oil Pay Zone, or Non-Bearing Sand) at every depth increment. The platform delivers a responsive 23-track depth-synchronized well log visualizer adhering to API RP 31A standards with 100\% screen-width fitting, alongside dynamic column and petrophysical formula managers for live operational calibration. Validation across 16 verified formation intervals yielded an overall classification accuracy of 81.3\%, 100.0\% sensitivity across commercial hydrocarbon zones, a pay-zone macro-$F_1$ score of 0.921 (outperforming conventional dual-ratio Pixler charts by +18.8\%), and sub-1.55-second computational latency for deep well trajectories ($15,000\text{ m}$), with a System Usability Scale (SUS) score of 82.5/100 (Grade A / Top 10th percentile). The application is deployed serverless on Vercel, democratizing advanced petrophysical computing with zero commercial licensing overhead.

\noindent\textbf{Keywords:} \textit{Gas While Drilling (GWD), Mud Logging, Hydrocarbon Fluid Forecasting, Deterministic Decision Support System, Petrophysics, Data Visualization, SPE PRMS Auditability.}
\end{abstracteng}
